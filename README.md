# Modern Tech & Design Blog Website

A responsive, accessible, and modern multi-page blog website built with clean HTML and Tailwind CSS. The project features three core article verticals: **Web Development**, **UI/UX Design**, and **Tech Infrastructure**, complete with dynamic CSS image animations, structured typography, and full mobile responsiveness.

##  Live Demo

- **Deployed URL:** [https://modern-blog-zeta.vercel.app/]
- **Repository:** [https://github.com/niyomubyeyi150-sudo/Modern-Blog-Website]

##  Features & Highlights

- **Dynamic Theme & Design:** Custom topic-based color coding with glowing borders and gradient accents.
- **Pure CSS Image Animations:** Continuous multi-image rotation and CSS keyframe animations across article banners (no heavy external JS dependencies).
- **Responsive Layout:** Mobile-first layout with smooth navigation, structured reading widths, and clean hierarchy.
- **Accessibility & Contrast:** WCAG-compliant color contrasts, semantic HTML elements (`<article>`, `<nav>`, `<header>`, `<footer>`), and clean typography scaling.
- **Real SVG / Icon Integration:** Consistent iconography across category badges, read times, and author metadata.
